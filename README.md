# Kharcha — Expenses & Budgets (PKR)

A simple Android app to track spending against monthly budgets in Pakistani Rupees.
Every month's data is kept, so you can look back at any previous month.

- **Home** – spent this month, budget left, a safe amount to spend per day, and each category's progress
- **Expenses** – every expense for the month, grouped by day, filter by category, tap to edit or delete
- **Custom categories** – tap **+ New** while adding an expense, or use Budgets → Add category
- **Credit** – record money that came in and the date, with the month's credit, spending and balance
- **Budgets** – set a monthly PKR budget per category, add/rename/remove categories
- **History** – month-by-month totals, saved vs. over budget, a 6-month chart
- **Settings (⚙)** – back up / restore your data, export to CSV (Excel)

Data is stored only on the phone, in the app's native storage. Nothing is sent anywhere.

## Install on your phone

The ready-to-install file is `Kharcha-v1.1.apk`.

**Option A – USB cable** (USB debugging switched on in Developer options):
```bash
~/Android/Sdk/platform-tools/adb install -r Kharcha-v1.1.apk
```

**Option B – no cable:** send `Kharcha-v1.1.apk` to your phone (WhatsApp to yourself, Google Drive,
or copy it over USB), tap it in the Files app, and allow "Install unknown apps" when Android asks.
Play Protect may warn because the app isn't from the Play Store; tap **Install anyway**.

## Back up your data

Settings ⚙ → **Share backup** (send it to Google Drive or WhatsApp) or **Save backup to phone**
(goes to `Documents/Kharcha`). Do this every month or so. **Uninstalling the app deletes its data**,
so restore from a backup with Settings ⚙ → **Restore from backup** if you reinstall.

## Project layout

| Path | What it is |
|---|---|
| `www/` | The app itself: `index.html`, `styles.css`, `app.js` (plain HTML/CSS/JS) |
| `src/native.js` | Exposes the Capacitor plugins to the app; bundled into `www/native.js` |
| `android/` | Native Android project generated by Capacitor |
| `keystore/` + `android/keystore.properties` | Release signing key and its passwords |

## Building a new version

Requires JDK 21, the Android SDK (platform 36, build-tools 36) and Node 22 (`nvm use 22`).

1. Change the code in `www/`.
2. Bump `versionCode` (e.g. `1` → `2`) and `versionName` in `android/app/build.gradle`.
3. Build:
   ```bash
   export ANDROID_HOME=$HOME/Android/Sdk
   npm run apk
   ```
   The signed APK is `android/app/build/outputs/apk/release/app-release.apk`.
4. Install it over the old one with `adb install -r …`. Your data stays.

> ⚠️ **Keep `keystore/kharcha-release.jks` and `android/keystore.properties` safe (copy them somewhere
> private).** Android only accepts an update signed with the same key. If they're lost, you'd have to
> uninstall the app (losing its data unless you have a backup) to install a new version.

The `www/` folder also works as an installable web app (PWA) if it's ever hosted over HTTPS.
